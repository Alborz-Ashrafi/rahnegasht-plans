## اجرا

فایل `index.html` صفحهٔ اصلی است. برای اجرای محلی از پوشهٔ پروژه:

```sh
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید.

## انتشار

برای نمایش وب، GitHub Pages را از شاخهٔ `main` و مسیر `/ (root)` فعال کنید. وجود فایل `.nojekyll` باعث می‌شود فایل‌ها بدون پردازش اضافی منتشر شوند.

فایل‌های ویدئویی فعلاً منتشر نشده‌اند. در کاتالوگ، پیام «نمونه‌ویدئو به‌زودی اضافه می‌شود» نمایش داده می‌شود. پس از آپلود ویدئوها در پوشهٔ `yaser` می‌توان مقدار `ENABLE_VIDEO_PREVIEWS` را در هر دو فایل کاتالوگ و صفحهٔ اصلی به `true` تغییر داد.
